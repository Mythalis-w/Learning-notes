一元线性回归就像是在寻找两个变量之间的"直线关系"。想象你在画一条直线，让这条直线尽可能接近所有的数据点。

$$Y = \beta_0 + \beta_1 X + \varepsilon$$

其中：
- $Y$：因变量（我们想要预测的值）
- $X$：自变量（用来预测的变量）
- $\beta_0$：截距（直线与Y轴的交点）
- $\beta_1$：斜率（X每增加1个单位，Y的变化量）
- $\varepsilon$：误差项（实际值与预测值的差异）

目的：让直线与所有数据点的的距离总和最小

# 1. 最小二乘法
拟合形式：$\hat y = \beta_0 + \beta_1 x$

 计算公式
$$
\beta_1=\frac{n\sum x_iy_i-\sum x_i \sum y_i}{n\sum x_i^2 - (\sum x_i)^2}
$$
$$
\beta_0=\bar{y}-\beta_1 \bar{x}
$$

 使用步骤
1. 整理样本数据 $(x_i,y_i)$；
2. 计算各项求和：$\sum x,\sum y,\sum xy,\sum x^2$；
3. 代入公式求得斜率 $\beta_1$；
4. 利用均值计算截距 $\beta_0$；
5. 得到回归方程 $\hat y=\beta_0+\beta_1 x$；
6. 采用 $R^2$、MSE 检验模型拟合效果。


# 2. 评价指标

## 1.决定系数 $R^2$

$$
R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}
$$

其中：
- $SSE$：残差平方和
- $SST$：总平方和
- $\hat{y}_i$：预测值
- $\bar{y}$：实际值的平均数

 取值范围和含义：
- 范围：$0 \le R^2 \le 1$
- $R^2 = 0$：模型完全无法解释数据变化
- $R^2 = 1$：模型完美解释所有数据变化
- $R^2 = 0.8$：模型解释了80%的数据变化

实际应用判断标准：
- $R^2 > 0.7$：拟合较好
- $0.5 < R^2 < 0.7$：拟合一般
- $R^2 < 0.5$：拟合较差


## 2.MSE均方误差
$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
$$
- 单位：与因变量的平方相同
- 敏感性：对大误差更敏感（因为有平方）
- 取值：越小越好，最小值为0

## 3.RMSE均方根误差
$$
RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}
$$
也就是MSE的开根就是RMSE
- 单位：与因变量单位相同
- 敏感性：对大误差更敏感（因为有平方）
- 取值：越小越好，最小值为0

## 4.MAE平均绝对误差
$$
MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|
$$

- 单位：与因变量相同
- 稳健性：不受异常值影响
- 直观性：容易理解和解释


| 指标 | 含义     | 优点                 | 缺点                     | 适用场景       |
| ---- | -------- | -------------------- | ------------------------ | -------------- |
| $R^2$ | 解释程度 | 无量纲，易比较       | 不反映预测精度           | 模型比较       |
| MSE  | 预测误差 | 数学性质好           | 单位是平方，难理解       | 模型优化       |
| RMSE | 预测误差 | 单位直观             | 对异常值敏感             | 预测精度评估   |
| MAE  | 预测偏差 | 稳健，易理解         | 数学性质较差             | 稳健性评估     |

# 3.结尾

我们一般最后拟合的对象是$\hat y = \beta_0 + \beta_1 x$
而没有残差项，残差项只在原理解释的方面去解释
