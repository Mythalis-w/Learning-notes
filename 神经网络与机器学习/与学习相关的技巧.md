# 1.参数的更新
神经网络的学习的目的是找到使损失函数的值尽可能小的参数。这是寻找最优参数的问题，解决这个问题的过程称为**最优化**
前面我们用了SGD最为最优化的方法，这一节会记录一些和SGD更好的方法。

## 1.Momentum
用数学式表达Momentum
$$
\begin{align*}
\boldsymbol{v} &\leftarrow \alpha \boldsymbol{v} - \eta \frac{\partial L}{\partial \boldsymbol{W}} \\
\boldsymbol{W} &\leftarrow \boldsymbol{W} + \boldsymbol{v}
\end{align*}
$$
和前面的SGD一样，和前面的SGD一样，$\boldsymbol{W}$表示要更新的权重参数，$\dfrac{\partial L}{\partial \boldsymbol{W}}$表示损失函数关于$\boldsymbol{W}$的梯度，$\eta$表示学习率。这里新出现了一个变量$\boldsymbol{v}$，对应物理上的速度。 式子表示了物体在梯度方向上受力，在这个力的作用下，物体的速度增加这一物理法则。Momentum方法给人的感觉就像是小球在地面上滚动，滚动到最低点

```python
class Momentum:
    def __init__(self, lr=0.01, momentum=0.9):
        self.lr = lr
        self.momentum = momentum
        self.v = None

    def update(self, params, grads):
        if self.v is None:
            self.v = {}
            for key, val in params.items():
                self.v[key] = np.zeros_like(val)

        for key in params.keys():
            self.v[key] = self.momentum*self.v[key] - self.lr*grads[key]  # 开始更新v
            params[key] += self.v[key]
            
            
'''
params = { "W1": W1, "W2": W2, "b1": b1, "b2": b2 } 类似
'''
```

代码中，momentum等效为摩擦力，在0-1之间， params存放参数（是一个字典），就是W和b，grads存放梯度

这个就是一个新的最优化方法。

## 2.AdaGrad
在学习率的有效技巧中，有一个技巧叫做**学习率衰减**，随着学习的进行，使学习率逐渐减小，但是学习率衰减是针对的全体学习率。

而AdaGrad优化了这种方法，针对每一个的参数，都定制了值，用数学式表示为
$$ \begin{align*} \boldsymbol{h} &\leftarrow \boldsymbol{h} + \frac{\partial L}{\partial \boldsymbol{W}} \odot \frac{\partial L}{\partial \boldsymbol{W}} \\ \boldsymbol{W} &\leftarrow \boldsymbol{W} - \eta \frac{1}{\sqrt{\boldsymbol{h}}}\frac{\partial L}{\partial \boldsymbol{W}} \end{align*} $$
这里第一个式子的乘法代表的是矩阵乘法，而h保存了以前的所有梯度值的平方和。而在更新参数的时候乘上$\frac{1}{\sqrt{\boldsymbol{h}}}$就可以调整学习的尺度，这意味着，参数的元素中变动较大的元素的学习率变小。
```python
class AdaGrad:
	def __init__(self, lr=0.01):
		self.lr =lr
		self.h = None
		
	def update(self, params, grads):
		if self.h is None:
			self.h={}
			for key, val in params.items():
				self.h[key]=np.zeros_link(val)
				
		for key in params.keys():
			self.h[key] += grads[key]*grads[key]
			params[key] -= self.lr * grads[key] / (mp.sqrt(self.h[key])+1e-7)
```

# 2.权重的初始值
我们知道，反向传播是需要神经网络中每一个单独的节点的导数的，而每一层都会有一个激活函数，比如sigmoid函数，他的曲线图在接近0和1的时候，斜率几乎为0，这也代表，我们在求这个节点的梯度的时候，反向传播的梯度值逐层下来会慢慢变小，比如：![[图片支持/与学习相关的技巧/反向传播.png]]
假如这是神经网络中的某个节点，E是反向传播过来的节点的总和，$y=f(x)$，而f代表的是sigmoid函数。如果，y这个点在初始的随机权重的影响下，十分接近1/0，那$\left(\dfrac{\partial y}{\partial x}\right)$就会变得接近于0，$E*\left(\dfrac{\partial y}{\partial x}\right)$也会接近于0，一个接近0的数乘什么都是0，那这个节点反向传播，再怎么传播都是0，这就导致，再更新权重的时候，$W_{new}=W_{old}-\eta*0$，这很明显是不合理的。 

所以，隐藏层的激活函数的输出数据的分布就很重要，如下图![[Sigmoid在使用标准差为1的高斯分布.png]]
标准差为1的时候分布是这样的，这很明显是不合理的，绝大多数节点的单层输出都是接近0/1的，因此，先人们研究了一些初始值，能避免这种情况

## 1. Xavier初始值
**可以用于激活函数是sigmoid、tanh的情况**，每一层的初始权重都要做这个初始值转换
$$ \sigma = \sqrt{\frac{2}{n_{in}+n_{out}}} $$
简化后也可以用$$ \sigma = \sqrt{\frac{1}{n_{in}}}$$
```python
node_num = 100 # 前一层的节点数
w = np.random.randn(node_num, node_num)/np.sqrt(node_num) #这个仅仅是示例，初始权重大小不一定是node_num*node_num的矩阵
```

$$ \sigma = \sqrt{\frac{2}{n_{in}}}$$

# 3. Batch Normalization（BN）
Batch Norm 可以强制性的调整激活值的分布，其主要操作就是插入以恶搞对数据分布进行正规化的层![[Batch Norm.png]]

Batch Norm以进行学习时的mini-batch为单位，按照mini-batch进行正规化，就是使数据分布的均值为0、方差为1的正规化。
$$ \begin{aligned} \mu_B &\leftarrow \frac{1}{m}\sum_{i=1}^{m} x_i \\ \sigma_B^2 &\leftarrow \frac{1}{m}\sum_{i=1}^{m} (x_i-\mu_B)^2 \\ \hat{x}_i &\leftarrow \frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\varepsilon}} \end{aligned} $$
这个就是Batch Norm做的所有事情，将输入数据 $\{x_1, x_2, \dots, x_m\}$ 变换为均值为0、方差为1的数据 $\{\hat{x}_1, \hat{x}_2, \dots, \hat{x}_m\}$，非常简单。通过将这个处理插入到激活函数的前面，可以减小数据分布的偏向。
然后，我们还要做一步缩放和变换
$$ y_i \leftarrow \gamma \hat{x}_i + \beta $$
这一步的作用是让神经网络通过反向传播来自己更新$\gamma、\beta$，一开始这两个分别等于1 0。
