# 1. 概念
如下图，我们把最左边的层叫做输入层(0)；最右边的叫做输出层(2)；中间叫做中间层(1)，也可以叫做隐藏层![[简单的神经网络.png]]
为了方便理解神经网络，再对感知机的形式做下改变
$$
y = h\left(b + w_1x_1 + w_2x_2\right)
$$

$$
h(x)=
\begin{cases}
0 & (x \le 0) \\
1 & (x > 0)
\end{cases}
$$
$h(x)$回把输入的x转为0/1，这种函数叫做**激活函数**，激活函数的作用在于决定如何激活信号输入的总和
$$
\begin{aligned}
a &= h\left(b + w_1x_1 + w_2x_2\right) \\
y &= h(a)
\end{aligned}
$$
如下图，上面的式子可以被如下表示;图中右面的大圈可以视为是一个神经元
![[明确显示激活函数.png]]

## 2.实现一个简单的三层前向神经网络
![[图1.png]]![[图2.png]]![[图3.png]]

根据这个图，我们可以写出下面的代码
```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def identity_function(x):
    return x

def init_network():
    network = {}
    network['W1'] = np.array([[0.1, 0.3, 0.5], [0.2, 0.4, 0.6]])
    network['b1'] = np.array([0.1, 0.2, 0.3])
    network['W2'] = np.array([[0.1, 0.4], [0.2, 0.5], [0.3, 0.6]])
    network['b2'] = np.array([0.1, 0.2])
    network['W3'] = np.array([[0.1, 0.3], [0.2, 0.4]])
    network['b3'] = np.array([0.1, 0.2])

    return network

def forward(network, x):
    W1, W2, W3 = network['W1'], network['W2'], network['W3']
    b1, b2, b3 = network['b1'], network['b2'], network['b3']

    a1 = np.dot(x, W1) + b1
    z1 = sigmoid(a1)
    a2 = np.dot(z1, W2) + b2
    z2 = sigmoid(a2)
    a3 = np.dot(z2, W3) + b3
    y = identity_function(a3)

    return y

network = init_network()
x = np.array([1.0, 0.5])
y = forward(network, x)
print(y)  # [ 0.31682708  0.69627909]
```

在这个神经网络中，前面几层的激活函数都是sigmoid函数，但是最后一层的激活函数用的是恒等函数，**输出层的激活函数$\sigma()$很特别，我们在后面会提到**

![[简易表示.png]]

如图，也可以简易表示成这样，每一个神经元都有其唯一的权重和偏置，如第一层的计算式子$$a_2^{(1)} = x_1 w_{21}^{(1)} + x_2 w_{22}^{(1)} + b_2^{(1)}$$
这个是第一层第二个神经元是怎么计算来的
## 3.输出层的设计

神经网络可以用在分类问题和回归问题上，不过需要根据情况改变输出层的激活函数。一般而言，**回归问题用恒等函数，分类问题用$\mathrm{softmax}$函数，二分用sigmoid**。

恒等函数就是把信号不变的输出，这里主要讲一下softmax

$$y_k = \frac{\exp(a_k)}{\sum_{i=1}^{n}\exp(a_i)}$$
上式就是softmax函数，分子是输入信号$a_k$的指数函数，分母是所有输入信号的指数函数的和
```python
def softmax(a):
	exp_a = np.exp(a)
	sum_exp_a = np.sum(exp_a)
	y = exp_a/sum_exp_a
	return y
```
但是softmax在取指数的过程中会出现数值溢出的情况，为了避免这样的问题，我们做如下改进![[softmax 的改进.png]]
上图说明，在softmax的指数运算中，任意添加一个常数C是不改变结果的，为了防止溢出，我们会使用输入信号中的最大值

所以上面代码改进后就是
```python
def softmax(a):
	c = np.max(a)
	exp_a = np.exp(a-c)
	sum_exp_a = np.sum(exp_a)
	y = exp_a/sum_exp_a
	return y
```

softmax函数的特征就是总和为1，所以，我们可以把softmax函数的输出解释为概率，这也是为什么它适合分类问题。

输出层的神经元数量是根据特定的问题来做的，对于分类问题，输出层的神经元数量一般设定为类别的数量（如0-9识别，分类问题，输出层需要10个神经元）
