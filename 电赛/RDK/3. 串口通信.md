# 1. 创建串口对象
```python
import serial

# 1. 打开串口
ser = serial.Serial(
    port="/dev/ttyS1",    # 串口设备名
    baudrate=115200,      # 波特率，和外设保持一致
    bytesize=8,           # 数据位固定8
    parity="N",           # 无校验
    stopbits=1,           # 停止位1
    timeout=0.01          # 读取超时时间
)

# 清空缓冲区，防止残留乱码
ser.flush()
```

# 2. 发送和接收

## 1. 发送字符串
```python
# 发送 dx,dy 格式
send_str = "-120.3,86.2\n"
ser.write(send_str.encode("utf-8"))
```
## 2. 发送二进制字节
```python
# 直接发字节数组
frame = bytearray([0x01,0xFD,0xE8,0x03,0x00,0x00,0x6B])
ser.write(frame)
```

## 3. 读取一行（读到换行符停止，最常用）
```python
recv = ser.readline()
# 转字符串
text = recv.decode("utf-8").strip()
print("收到：", text)
```

## 4.读取固定长度字节（读取驱动器应答 7 字节）
```python
data = ser.read(7) # 一次性读7个字节
```

## 5. 关闭窗口
```python
ser.close()
```

# 3. 示例
```python
import serial
import time

# 初始化串口
ser = serial.Serial("/dev/ttyS1", 115200, timeout=0.01)
ser.flush()

# 循环发送
while True:
    # 发文本
    ser.write(b"100,-50\n")
    # 读回复
    res = ser.readline()
    print(res)
    time.sleep(0.1)

ser.close()
```
