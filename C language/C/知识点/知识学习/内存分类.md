
C 程序编译后，会以三种形式使用内存：
### 静态 / 全局内存
静态声明的变量和全局变量使用这部分内存，这些变量在程序开始运行时分配，直到程序终才消失。
### 自动内存（栈内存）
函数内部声明的变量使用这部分内存，在函数被调用时才创建。
每一次写代码会自动开辟空间，也会自动释放
### 动态内存（堆内存）
根据需求编写代码动态分配内存，可以编写代码释放，内存中的内容直到释放才消失。

# 1. 动态内存分类
这里先要讲下主要就是用 `malloc(memory allocata)` 函数进行分配，返回一个指针指向开辟的空间地址

而`malloc`这个函数来自于==`stdlib.h`==这个库
具体使用方法是`void* malloc(size_t size)` 
- **返回值`void*`**：通用无类型指针，可以隐式转换成任意其他类型的指针，用来接收分配到的内存首地址；分配失败（堆空间不足）时返回空指针`NULL`。
- **参数`size_t size`**：`size_t`是无符号整数类型(sizeof的返回类型)，参数`size`代表你想要申请的**内存字节总数**。

举例为`int* arr = (int*)malloc(10 * sizeof(int));`
这样就从堆申请了10个int字节的内存，指针存放于arr

```C
if (arr == NULL) { // 内存申请失败，做容错处理，比如退出程序、提示信息 
perror("malloc failed"); 
return 1; 
}
```
下面是如何使用这一块内存
```C
for(int i=0; i<10; i++){ arr[i] = i; }
```
用完也要释放内存
```C
free(arr); 
arr = NULL; // 释放后置空，防止野指针
```

字符串的实例
```C
#include <stdio.h>  
#include <stdlib.h>  
#include <string.h>  
  
int main(){  
    char *s;  
    s = (char*)malloc(10);  
    strcpy(s,"Helloa");  
    printf("%s\n", s);  
    free(s);  
    return 0;  
}
```

结构体的实例
```C
#include <stdio.h>  
#include <stdlib.h>    
  
typedef struct{  
    int x;  
    int y;  
}po;  
  
int main(){  
    po *p;  
    p = (po*) malloc(sizeof(po));  
    (*p).x = 10;  
    (*p).y = 20;  // (*p).y  == p->x
    printf("%d %d",(*p).x,(*p).y);  
    free(p);  
    return 0;  
}
```
