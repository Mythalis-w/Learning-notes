`cout` 是 C++ 标准库中的输出流对象，定义在 `<iostream>` 头文件中，且位于 `std` 命名空间。如果编译报错 `'cout':undeclared identifier`，最常见的原因就是**没有包含 `<iostream>` 头文件**，导致编译器无法识别 `cout`。

- 选项 A 错误：`cout` 不是普通变量，无需手动声明；
- 选项 B 错误：拼写错误会提示 “找不到该标识符”，但题目未体现拼写问题，且 “忘记包含头文件” 是更直接的原因；
- 选项 D 错误：缺少`main()`函数会报链接错误，而非编译期的标识符未定义错误。

### 2-5

**答案：D. 结构**

**解析**：

面向对象程序设计（OOP）的三大核心特征是：

- **封装**：将数据和操作封装在类中，隐藏内部实现细节
- **继承**：允许一个类继承另一个类的属性和方法，实现代码复用

“结构” 是 C 语言中一种复合数据类型，并非面向对象的核心特征。

### 2-6

**答案：D. 消息**

**解析**：

在面向对象系统中，不同对象之间通过 ** 消息（Message）** 进行通信。一个对象向另一个对象发送消息，请求其执行某个操作（调用方法），这是对象间交互的基本方式。

- 属性：对象的静态特征（数据）
- 封装：将数据和方法打包在类中的机制
- 类：对象的抽象模板，不是通信机制

而对于属性：
在面向对象里，一个对象由两部分组成：

- **属性（也叫成员变量 / 字段）**：描述对象的**静态特征 / 状态**，就是 “它有什么”。
    比如一个`Student`对象，它的`name`（姓名）、`age`（年龄）、`score`（分数）就是属性，这些是数据。
- **方法（也叫成员函数 / 行为）**：描述对象的**动态行为 / 功能**，就是 “它能做什么”。
    比如`Student`对象的`study()`（学习）、`takeExam()`（考试），这些是函数。
成员 = 属性（数据） + 方法（函数）

8. 拷贝构造函数：**用一个已有的对象，创建一个一模一样的新对象**，这时候调用的构造函数，就是**拷贝构造函数**

    用已存在的对象 `c` 去初始化新对象 `d`，触发**拷贝构造函数**。
- `AA e = d;` ✅
    这是 “拷贝初始化”，和 `AA e(d);` 等价，同样触发**拷贝构造函数**
```Cpp

AA d;
e=d;//不触发拷贝初始化
```
	`A& r = a;` → 这是引用绑定，不调用任何构造函数，只是给a起了一个别名
	因此大部分的引用其实都只是地址的传递，而不是构造一个新对象
```Cpp

public:
    A(const A& other) { }   // 参数是 const 引用
};

A a;
A b(a);   // ✅ 调用拷贝构造，这里 a 是对象，不是引用
```

| -------------------------------- | -------- | ---------------- |
| 普通函数的形参是引用（如 `void f(const A&)`） | ❌ 不调用    | 只是绑定别名           |
| 定义新对象并用已有对象初始化（如 `A b(a);`）      | ✅ 调用     | 拷贝构造函数的语义就是创建新对象 |

14. 友元函数==不是类的成员函数，==它只是被授予了访问权限的**外部函数**，不隶属于类，也没有 `this` 指针。
    友元函数的访问权限是**完全开放的**，它可以访问类的所有成员，包括 `private` 和 `protected` 成员。
    如果函数 `fun` 被声明为类 `A` 的友元函数,友元函数的参数完全可以是 `A` 类型，这是非常常见的用法。例如，重载运算符 `+` 或 `<<` 时，参数就是 `const A&` 类型。
 ```Cpp
    class A { 
    friend ostream& operator<<(ostream& os, const A& obj); // 参数是A的引用 
    };
    ```
友元关系**不传递、不继承、不可逆
友元**破坏了**类的封装性和数据隐藏性，因为它允许外部直接访问私有成员。
数据的隐藏性是由 private 关键字实现的，友元恰恰是**打破**这种隐藏。
其主要目的是**为了性能优化,提高程序的效率
友元类里的所有成员函数都是友元函数
友元类只是获得了访问权限，并不会让两个类的成员互相成为对方的成员。类 A 和类 B 仍然是独立的两个类，各自的成员也不属于对方。
类内定义(友元函数可以在类内定义，也可以在类外定义)的友元函数的调用方式和全局函数一样
友元在内部定义和声明必须friend，外部定义如果在内部声明了就不用friend

16. 在 C++ 中，运算符重载函数的参数个数与其是成员函数还是友元函数，以及运算符的元数（一元/二元）有关。
    - **重载为成员函数**：隐含 `this` 指针作为第一个操作数。因此参数表中参数的个数等于**操作数个数减 1**。
    
    - **一元运算符**（如 `++`、`--`）：操作数个数为 1（即对象自身），参数表为 **0** 个参数。
        
    - **二元运算符**（如 `+`、`-`）：操作数个数为 2，参数表为 **1** 个参数（代表右操作数）。
        
- **重载为友元函数**：没有隐含的 `this` 指针。因此参数表中参数的个数等于**操作数个数**。
    
    - **一元运算符**（如 `++`、`--`）：操作数个数为 1，参数表为 **1** 个参数。
        
    - **二元运算符**（如 `+`、`-`）：操作数个数为 2，参数表为 **2** 个参数。
