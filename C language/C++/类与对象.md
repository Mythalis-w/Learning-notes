
# 1.类和对象

在C++中，允许使用class和struct两种方法去定义类，其中，class默认所有的类都是私有的，struct默认所有的类都是共有的，除此以外，两者完全等价。

```C++
class Student {
// 默认是 private 区域
    std::string private_name;  // 这个是私有的，类外不能访问

public:  // 从这里开始，后面的成员都是公有的
    std::string name;  // 公有的
    int age;           // 公有的

    void display() {   // 公有的成员函数
        // 在类的内部，可以访问私有成员
        private_name = "内部可访问"; 
    }

private: // 又可以切换回私有区域
    double secret_score; // 又是私有的了
};
```
类访问其中的共有属性或者共有的成员时，使用`class_name.name`

类类型也有指针变量
```C++
student stu;
student *p = &stu;
(*p).name = "Liping"
student student[3];
p = student+2;
```
指针指向动态分配的内存也是可以的
```C++
student *p = new student;
p -> name = "Wangping";

```

## 构造函数

这一点和python中的__init__很像，每一个类在创建的时候都会自己生成并调用一个构造函数，我们上面的类并没有实现将参数传入程序的作用，构造函数就可以实现传入参数的作用
注意，构造函数应该放在public中

例子如下
```C++
#include<iostream>  
#include<string>  
using namespace std;  
  
class student{  
private:  
    string name;  
    int id;  
    double score;  
public:  
    student(string s,int i ,double n){  
        name = s; id = i; score =n;  
    }  
    void print(){  
        cout << name <<" "<< id<<" " << score<<endl;  
    }  
};  
  
int main(){  
    string name;  
    int id;  
    double score;  
  
    cout << "name " << "id " << "score";  
    cin >> name >> id >> score;  
  
    student stu(name , id ,score);  
    stu.print();  
    return 0;  
}
```

==如果你想写构造函数，但是只是想写出来，可以`name(){;}`，和大部分类型一样，不想写东西就写一个；== 

在对象建立数组的时候，也要调用构造函数，数组中有几个元素就要调用几次构造函数
```C++
class Point{
	int x,y;;
public:
	Point(int a, int b);
	void print();
};
Point::Point(int a=0, int b=0){
	x=a;y=b;
}

int main(){
	Point p1;
	Point p2[3]={Point(1,1),Point(2,2),Point(3,3)} // 调用三次构造函数
}
```
除了构造函数可以传入参数，类还可以通过初始化列表来赋值,但是这种初始化顺序和声明顺序必须一样，也叫做：初始化列表

```C++
class Example {
    std::string s;
    int i;
public:
    // 低效方式：s先被默认构造为空字符串，然后被赋值为"Hello"
    Example() {
        s = "Hello"; 
        i = 10;
    }

    // 高效方式：s直接通过列表初始化初始化为"Hello"
    Example() : s("Hello"), i(10) {
    }
};
```
## 构造函数的重载

构造函数允许写多个，只要函数标签不同就可以
```C++
class Student {
private:
    string name;
    int age;
    double score;
    
public:
    // 1. 无参构造函数
    Student() {
        name = "Unknown";
        age = 0;

    }
    
    // 2. 单参数构造函数

        name = n;
        age = 0;
        score = 0.0;
        cout << "单参数构造" << endl;
    }
    
    // 3. 双参数构造函数
    Student(string n, int a) {
        name = n;
        age = a;
        score = 0.0;
        cout << "双参数构造" << endl;
    }
    
    // 4. 三参数构造函数
    Student(string n, int a, double s) {
        name = n;
        age = a;
        score = s;
        cout << "三参数构造" << endl;
    }
    
    void display() {
        cout << name << ", " << age << ", " << score << endl;
    }
};

int main() {
    Student s1;                    // 调用无参构造
    Student s2("张三");             // 调用单参数构造
    Student s3("李四", 20);         // 调用双参数构造
    Student s4("王五", 22, 95.5);   // 调用三参数构造
    
    return 0;
}
```

## **同类互访**
访问控制作用于类，而非对象。成员函数可以访问任何该类对象的私有成员
这个东西在重载的时候比较常见。

说的通俗一点，就是如果你定义了一个类Complex，那么如果你在类的定义里又写了一个Complex c1，那你可以在这个类里面访问c1的私有，因为c1也是complex类，如果c1不是complex，或者c1没有定义在Complex这个类的定义里，那么就不能访问了
```Cpp
class Complex {
    int real;
    int image;
public:
    Complex(int r = 0, int i = 0) : real(r), image(i) {}
    
    // 在类的定义里，又写了一个 Complex c1
    void test(Complex c1) {
        // ✅ 可以访问 c1 的私有成员
        cout << c1.real;   // 没问题！
        cout << c1.image;  // 没问题！
        
        // 因为 c1 也是 Complex 类
        // 你在这个类里面，同类之间随便看
    }
};
```
# 2.内联函数

内联函数是C++中的一个特性，用关键字 `inline` 修饰，目的是**减少函数调用的开销**。

- 普通函数调用：需要压栈、跳转、返回等操作
- 内联函数：在==**编译**时**将函数体直接插入**到调用处==，像宏一样展开，但保留了函数的语法特性

```C++
// 普通函数
int add(int a, int b) {
    return a + b;
}
int result = add(3, 5);  // 调用函数，有开销

// 内联函数
inline int add(int a, int b) {
    return a + b;
}
int result = add(3, 5);  // 编译时直接替换为 3 + 5
```

可以消除一部分函数调用的开销
==注意：类内定义的函数通常是默认内联的 ; 而复杂的函数哪怕写了inline也可能不会内联，这个看编译器了,inline修饰只是给编译器建议是否内联，而不是强制。==

# 3. 析构函数

析构函数是C++中一个特殊的成员函数，在对象**被销毁时自动调用**，用于执行清理工作。

- 特性：
- **无参数**，无返回值
    
- **不能重载**（每个类只有一个析构函数）
    
- 对象销毁时**自动调用**
    
- 主要用途：**释放资源**（堆内存、文件句柄、网络连接等）

# 4. 友元函数 和 友元类

**友元函数**（Friend Function）是 C++ 中定义在类的外部，但有权访问类的所有私有（private）成员和保护（protected）成员的普通函数。

友元关系**不传递、不继承、不可逆**

其特点就是在类内被声明，但是定义要写在外面(内部声明内部定义也是可以的，但是不常见)。类的内部，使用关键字 `friend` 加上函数的原型进行声明，可以放在类的私有和公有部分，都是可以的。

==友元函数只允许被传入进来的参数来进行私有访问==
```Cpp
void func(A a1, A a2) {
    A a3;  // 局部对象
    cout << a3.secret;  // ❌ 错误！不能访问 a3 的私有成员
    
    A* a4 = new A();
    cout << a4->secret;  // ❌ 错误！也不能访问
}
```
但是a1,a2就可以访问他们的私有

友元函数==不是类的成员函数，==它只是被授予了访问权限的**外部函数**，不隶属于类，也没有 `this` 指针。

```C++
#include<iostream>
using namespace std;

class student{
    int id;
    double grade;
public:
    void setData(int i, double s){
        id = i;
        grade = s;
    }
    friend double average(student *p, int count);
};

double average(student *p, int count){
    if(count == 0) return 0;
    double sum = 0;
    for(int i = 0; i < count; i++){
        sum += (*(p+i)).grade;
    }
    return sum / count;
}

int main() {
    student stu[101];
    int id;
    double score;
    int count = 0;
    
    while (true) {
        cin >> id;
        if (id == 0) break;
        
        cin >> score;
        stu[count].setData(id, score);
        count++;
    }
    
    double avg = average(stu, count);
    cout << avg << endl;
    
    return 0;
}
```
类内定义的友元函数的调用方式和全局函数一样
==也可以定义一个函数作为两个类共有的友元函数，但是这么做需要前向声明，不然会报错==
```Cpp
#include<iostream>
using namespace std;

class Boat{
    int weight;
public:
    Boat(int n):weight(n){}

    friend int getTotalWeight(Boat c1,Car c2);
};

class Car{
    int weight;
public:
    Car(int n):weight(n){}

    friend int getTotalWeight(Boat c1,Car c2);
};

int getTotalWeight(Boat c1,Car c2){
    return c1.weight + c2.weight;
}

int main(){
    int n,m;
    cin>>n>>m;
    Boat boat(n);
    Car car(m);
    cout<<"船和汽车共重"<<getTotalWeight(boat,car)<<"吨"<<endl;
}
```
这么写就会报错，因为没有前向声明`class Car;`，编译器不知道Car是一个类，那么友元就会声明失败，导致出现问题，所以要在`class Boat`前面加上前向声明 

除此以外，友元函数内可以调用友元函数，只要前面有声明就可以
### 前向声明

前向声明后只能定义指针或引用，不能定义对象，不能调用成员函数，不能访问成员。
```Cpp
// 前向声明：告诉编译器有一个类 B
class B;  

class A {
public:
    void setB(B* bPtr);   // 可以用 B*（指针）
    void useB();
private:
    B* b;                 // 可以用 B* 成员
    // B obj;            // ❌ 错误：不能定义对象，因为B不完整
    // void test(B b);   // ❌ 错误：值参数也需要完整定义
};

// 现在定义 B，然后才能定义 A 的成员函数
class B {
public:
    void doSomething() {}
};

// 在 A 的成员函数中可以使用 B 的成员，因为此时 B 已经完整定义
void A::setB(B* bPtr) { b = bPtr; }
void A::useB() { if(b) b->doSomething(); }
```

## 友元类

**友元类**是一个可以访问另一个类的**私有（private）和保护（protected）成员的类**。 (友元类里的所有成员函数都是友元函数)

简单理解：如果A类声明B类是它的友元类，那么B类的**所有成员函数**都可以访问A类的私有和保护成员，就好像这些成员是B类自己的一样。
```Cpp
class A {
private:
    int secret = 42;

    // 声明 B 是 A 的友元类
    friend class B;
};

class B {
public:
    void show(A& obj) {
        // ✅ 合法：B 是 A 的友元类，可以访问 A 的私有成员
        cout << obj.secret << endl;
    }

    void modify(A& obj, int val) {
        // ✅ 合法：同样可以修改私有成员
        obj.secret = val;
    }
};

class C {
public:
    void show(A& obj) {
        // ❌ 非法：C 不是 A 的友元类，不能访问私有成员
        // cout << obj.secret << endl;
    }
};
```
 友元类的关键特点

| 特性       | 说明                                       |
| -------- | ---------------------------------------- |
| **批量授权** | 一次性让另一个类的**所有成员函数**都成为友元，不需要逐个声明。        |
| **单向性**  | A 是 B 的友元类，不代表 B 是 A 的友元类（除非也主动声明）。      |
| **不可传递** | A 是 B 的友元类，B 是 C 的友元类，但 A **不是** C 的友元类。 |
| **不可继承** | A 是 B 的友元类，但 A 的派生类**不会自动成为** B 的友元类。    |
友元类只是获得了访问权限，并不会让两个类的成员互相成为对方的成员。类 A 和类 B 仍然是独立的两个类，各自的成员也不属于对方。

# 5. 类的继承（派生类）

我们首先讲解protected访问修饰符：`protected` 是C++类中的**访问控制修饰符**，它的访问权限介于 `public` 和 `private` 之间。

虚继承先继承虚基类再基类
### 访问权限对比
| 派生类访问修饰符      | 本类内部  | 派生类内部  | 外部（其他函数/对象） |
| ------------- | ----- | ------ | ----------- |
| **public**    | ✅ 可访问 | ✅ 可访问  | ✅ 可访问       |
| **protected** | ✅ 可访问 | ✅ 可访问  | ❌ 不可访问      |
| **private**   | ✅ 可访问 | ❌ 不可访问 | ❌ 不可访问      |
只要不是本类中，哪怕是main函数中该类的对象，外部都不能访问

| 继承方式        | 基类的public成员 | 基类的protected成员 | 基类的private成员 |
| ----------- | ----------- | -------------- | ------------ |
| public继承    | 仍是public    | 仍是protected    | 不可直接访问       |
| protected继承 | 变为protected | 变为protected    | 不可直接访问       |
| private继承   | 变为private   | 变为private      | 不可直接访问       |
讲完了protected，可以讲派生类了，派生类就是类的继承
语法：
```C++
class 基类 {
    // 基类成员
};

class 派生类 : 访问说明符 基类 {
    // 派生类特有的成员
};
```
访问说明符有三种，即private public protected ，**举个例子，T 继承 就是在基类中 public、protected和privite 中的所有东西都能被继承，访问说明符不一样，具体访问如下**

==**派生类继承了基类的所有成员变量和成员函数，但最终在派生类中的访问权限，由“基类原有的访问修饰符”和“继承方式修饰符”共同决定（取两者中更严格的）。**==

```C++
class Base {
public:
    int a;    // public成员
protected:
    int b;    // protected成员
private:
    int c;    // private成员，会被继承但不可直接访问
};

// 1. public继承
class DerivedPublic : public Base {
public:
    void func() {
        a = 1; // ✅ 可访问：基类public → 派生类仍public
        b = 2; // ✅ 可访问：基类protected → 派生类仍protected
        // c = 3; ❌ 不可直接访问：基类private成员
    }
};

// 2. protected继承
class DerivedProtected : protected Base {
public:
    void func() {
        a = 1; // ✅ 可访问：基类public → 派生类变为protected
        b = 2; // ✅ 可访问：基类protected → 派生类仍protected
        // c = 3; ❌ 不可直接访问
    }
};

// 3. private继承
class DerivedPrivate : private Base {
public:
    void func() {
        a = 1; // ✅ 可访问：基类public → 派生类变为private
        b = 2; // ✅ 可访问：基类protected → 派生类变为private
        // c = 3; ❌ 不可直接访问
    }
};
```
(即我们必须注意，基类的访问修饰符和派生类的访问说明符并不是一个东西)
示例：

```C++
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() { cout << "Eating" << endl; }
    
protected:
    void sleep() { cout << "Sleeping" << endl; }
    
private:
    void breathe() { cout << "Breathing" << endl; }  // 永远无法被继承
};

// 默认 private 继承
class Cat : Animal {  // 相当于 private Animal
public:
    void catAction() {
        eat();      // ✅ 可以（变成 private 成员）
        sleep();    // ✅ 可以（变成 private 成员）
        // breathe(); // ❌ 永远不能访问 private 成员
    }
};

// 显式 public 继承（通常想要的方式）
class Dog : public Animal {
public:
    void dogAction() {
        eat();      // ✅ 可以（保持 public）
        sleep();    // ✅ 可以（保持 protected）
    }
};

int main() {
    Cat cat;
    Dog dog;
    
    // Cat 是 private 继承
    // cat.eat();  // ❌ 错误！eat 在 Cat 中是 private
    
    // Dog 是 public 继承
    dog.eat();      // ✅ 可以！eat 保持 public
    
    // dog.sleep();  // ❌ 错误！sleep 是 protected，外部不能访问
    
    return 0;
}
```

==**注意：构造函数，析构函数，赋值运算符，转换函数，友元函数不用被继承；但是静态成员函数可以被继承

## 虚继承（虚基类）

虚继承 = 解决菱形继承
结构像菱形：
```C++
    Person
   /    \
Teacher Athlete
   \    /
  Student
```
- `Teacher` 和 `Athlete` 都继承 `Person`
- `Student` 同时继承 `Teacher` 和 `Athlete`
**如果不加 virtual（普通继承）：**
- Student 里会有 **两份 Person**（一份来自 Teacher，一份来自 Athlete）
- 数据重复、占内存
- 访问 `name`、`age` 时编译器不知道用哪一份 → **二义性错误**


```Cpp
#include <iostream>
#include <string>
using namespace std;

class Person {
public:
    string name;
    int age;
    Person(string n, int a) : name(n), age(a) {}
};

// 虚继承：共享同一份 Person
class Teacher : virtual public Person {
public:
    Teacher(string n, int a) : Person(n,a) {}
};

// 虚继承：共享同一份 Person
class Athlete : virtual public Person {
public:
    Athlete(string n, int a) : Person(n,a) {}
};

// 底层类
class Student : public Teacher, public Athlete {
public:
    // 注意：虚继承必须由 最底层子类 负责初始化顶层父类
    Student(string n, int a) 
        : Person(n,a), Teacher(n,a), Athlete(n,a) {}
};

int main() {
    Student s("李四", 19);

    // ✅ 不再二义性，只有唯一一份 Person
    cout << s.name << " " << s.age << endl;

    return 0;
}
```
## 派生类调用基类构造函数

```C++
#include <iostream>
#include <string>
using namespace std;

// 基类：动物
class Animal {
protected:
    string name;
    int age;
    
public:
    // 基类有参构造函数
    Animal(string n, int a) : name(n), age(a) {
        cout << "Animal 构造函数被调用: " << name << ", " << age << "岁" << endl;
    }
    
    void display() {
        cout << "名字: " << name << ", 年龄: " << age << "岁";
    }
};

// 派生类：狗
class Dog : public Animal {
private:
    string breed;  // 品种
    
public:
    // 派生类构造函数调用基类构造函数
    Dog(string n, int a, string b) : Animal(n, a), breed(b) {
        cout << "Dog 构造函数被调用: 品种=" << breed << endl;
    }
    
    void show() {
        display();
        cout << ", 品种: " << breed << endl;
    }
};

int main() {
    cout << "=== 创建Dog对象 ===" << endl;
    Dog myDog("旺财", 3, "金毛");
    myDog.show();
    
    return 0;
}
```

派生类的构造函数想要调用基类的构造函数都是通过初始化列表的方式去调用，且必须通过这一种方式去调用

如果要继承多个基类
```C++
class Derived : public Base1, public Base2, public Base3 {
```
就可以了

如果基类构造函数（可以是虚基类）是无参或者**全缺省参数**的构造函数，那么可以在派生类中隐式调用(“显式调用”主要指**在初始化列表中写出基类/成员构造**，隐式调用反着来)

`A* p = new A(10);   // A(10) 这里的构造是编译器自动在 new 内部调用，通常仍称为隐式调用`

但 `placement new` 通常被视为**显式调用**，因为程序员直接写出了构造函数名：

`new(buf) A(10);   // 显式调用构造函数`

# 6. 指针

## this指针

this指针是一个**隐含的指针**，它指向**当前对象本身**。当你在类的成员函数中访问成员变量或其他成员函数时，this指针就在背后起作用。

```C++
class Person {
private:
    string name;
    int age;
    
public:
    Person(string name, int age) {
        // 使用this指针区分参数和成员变量
        this->name = name;  // 左边的name是成员变量，右边的name是参数
        this->age = age;     // this->age表示当前对象的age
    }
    
    void introduce() {
        // 这里实际上隐含了this指针
        cout << "我叫" << this->name << "，今年" << this->age << "岁" << endl;
        // 等价于：cout << "我叫" << name << "，今年" << age << "岁" << endl;
    }
    
    // 返回当前对象的引用
    Person& growOlder() {
        this->age++;
        return *this;  // 返回当前对象本身
    }
};
```

## 对象指针

- 每个对象在初始化后都会在内存中占一定的空间，因此，既可以通过对象名访问一个对象，也可以通过对象地址来访问一个对象；
    `类名 *对象指针名;`
- 使用指向对象的指针来访问对象成员，要用 “`->`” 操作符；
- 每个对象的存储空间只是该对象数据成员所占用的存储空间，函数代码存储在对象空间之外；
- C++ 编译系统只用一段空间来存放共同的函数代码段，在调用各对象的成员函数时，都去调用这个公用的函数代码；

```C++
#include <iostream>
using namespace std;

// 定义Point类
class Point
{
    int x, y; // 数据成员：每个对象独有，占对象内存
public:
    // 构造函数：函数代码是所有对象共用的
    Point(int a = 0, int b = 0) : x(a), y(b) {}
    
    // 成员函数print：函数代码是所有对象共用的
    void print() {
        cout << "(" << x << "," << y << ")" << endl;
    }
};

int main() {
    // 1. 通过对象名访问对象
    Point p1(1, 1);
    cout << "通过对象名p1访问print()：";
    p1.print(); // 用.操作符访问成员

    // 2. 通过对象指针访问对象（对应知识点1、2）
    Point *p2 = &p1; // 定义对象指针，指向p1的地址
    cout << "通过指针p2访问print()：";
    p2->print();    // 用->操作符访问成员（指针专用）
    // 等价写法：(*p2).print(); （先解引用，再用.）

    return 0;
}
```
# 7.静态成员

在 C++ 中，静态成员是属于**整个类**而非类的某个对象的成员（因此没有this指针），分为**静态成员变量**和**静态成员函数**。可以把它理解为：类的 “共享资源”，所有对象共用这一份数据 / 方法，不随对象创建 / 销毁而变化。
(且静态成员的初始在程序启动阶段（main 函数执行之前）就完成了初始化( **编译阶段**：在类内只是声明，不分配内存、不初始化。))

其中，静态成员是写在类里面的，但是静态变量就是写在外面的
==静态成员变量必须在类外初始化（除了 `const static` 整型成员可以在类内直接初始化），静态成员函数可以直接在类内定义==
下面举一个静态成员变量(没有this指针)的例子
```C++
#include <iostream>
using namespace std;

class Student {
public:
    string name;          // 普通成员变量（每个对象独有）
    static int totalNum;  // 静态成员变量（所有学生共享的总人数）
    // 构造函数
    Student(string n) : name(n) {
        totalNum++;  // 每创建一个对象，总人数+1
    }
};

// 静态成员变量类外初始化（语法：类型 类名::变量名 = 初始值） 类外定义
int Student::totalNum = 0;  

int main() {
    Student s1("张三");
    Student s2("李四");
    
    // 两种访问方式：对象访问 / 类名直接访问（推荐）
    cout << "通过对象访问：" << s1.totalNum << endl;  // 输出2
    cout << "通过类名访问：" << Student::totalNum << endl;  // 输出2
    
    // 修改静态变量，所有对象共享
    Student::totalNum = 5;  //对象名.静态变量也是可以访问的
    cout << s2.totalNum << endl;  // 输出5
    return 0;
}
```

## 静态成员函数：
- 属于类而非对象，没有隐含的`this`指针； （因此无法访问普通成员）
- 只能访问**静态成员变量 / 静态成员函数**，不能访问普通成员（因为普通成员依赖具体对象）；
- 可以通过类名直接调用，无需创建对象。

```C++
#include <iostream>
using namespace std;

class Calculator {
public:
    static int sum;  // 静态成员变量：累计求和结果
    // 静态成员函数：计算两数之和并累计
    static int add(int a, int b) {
        sum += (a + b);  // 只能访问静态成员sum
        return a + b;
    }
};

int Calculator::sum = 0;  // 初始化静态变量

int main() {
    // 无需创建对象，直接通过类名调用静态函数
    cout << "1+2=" << Calculator::add(1, 2) << endl;  // 输出3
    cout << "累计和：" << Calculator::sum << endl;     // 输出3
    
    Calculator::add(3, 4);
    cout << "累计和：" << Calculator::sum << endl;     // 输出10
    return 0;
}
```

这两种方法一般在统计类的对象的时候去使用.
虽然 静态成员不属于对象，而是属于类，但是类的对象想去调用静态成员的时候还是可以做到的
- `类名::静态成员名`（推荐方式）
- `对象名.静态成员名`（也可以正常使用）

# 8.纯虚函数和虚函数，重写

在一个类内，如果有函数定义类似于`virtual double getArea()=0;` ，即函数前面有virtual并且后面有=0，则这个函数就是一个纯虚函数，这个函数的定义强制要求在派生类里面去写；普通虚函数（前面有virtual，但是后面没有=0）的定义不用强制在派生类去写(构造函数不能是虚函数，但是析构函数可以是)

想要是虚函数，首先必须要有this指针，然后才能写虚函数，像友元函数和静态成员函数都是没有this之后着呢的，所以不能成为虚函数；并且构造函数不能是虚函数

如果一个类里面有至少一个纯虚函数（只要有纯虚函数,普通虚函数是不可以的），那么这个类被称为抽象类，==为了去理解抽象类：我认为把抽象类理解为“**类的半成品模板**”或“**规定了基本结构的模板**”是比较形象的。==

**纯虚函数可以在抽象类外给出实现体**
```Cpp
class Base {  // Base是抽象类
public:
    virtual void func() = 0;  // 声明为纯虚函数
};

// 纯虚函数的定义（提供函数体）—— 在类外，但Base仍然是抽象类
void Base::func() {
    cout << "纯虚函数也可以有实现" << endl;
}
```

抽象类不能进行实例化
```C++
class Area {
public:
    virtual double getArea() = 0;  // 纯虚函数
};

int main() {
    // ❌ 错误：不能实例化抽象类
    // Area a;                    // 编译错误！
    // Area* p = new Area();      // 编译错误！
    
    // ✅ 正确：可以定义指针和引用
    Area* ptr;                    // 指针可以定义
    Area& ref = *ptr;             // 引用可以定义
    
    return 0;
}
```

派生类必须重写纯虚函数，如果抽象类里面有n个纯虚函数，那么派生类就必须重写n个纯虚函数，不然派生类也会变成抽象类

1. **纯虚函数**：`virtual double getArea() = 0;` 使 `Area` 成为抽象类
2. **不能实例化**：无法创建 `Area` 的对象，只能创建其派生类的对象
3. **必须实现**：派生类必须重写纯虚函数，否则派生类也会成为抽象类
4. **多态性**：可以通过基类指针调用派生类实现的 `getArea()` 函数 

抽象类中的纯虚函数在派生类中在定义也有要求,即有override标识符,用于在派生类中**显式声明**某个成员函数是要重写基类的虚函数。
```C++
class Base {
public:
    virtual void func1();
    virtual void func2(int x);
    virtual void func3() const;  // 普通虚函数
    virtual void func4() = 0;  // 纯虚函数也可以重写
};

class Derived : public Base {
public:
    // ✅ 正确：明确表示要重写 func1
    void func1() override {
        cout << "重写 func1" << endl;
    }
    
    // ✅ 正确：重写 func2
    void func2(int x) override {
        cout << "重写 func2, x = " << x << endl;
    }
    
    // ✅ 正确：重写 const 成员函数
    void func3() const override {
        cout << "重写 func3" << endl;
    }
    
    // ✅ 正确：重写纯虚函数
    void func4() override {
        cout << "实现纯虚函数" << endl;
    }
};
```

而对于虚函数，虚函数相较于抽象函数的区别就是虚函数不会把这个类变成抽象类，它可以正常的实例化，并且调用的时候也可以正常调用，在派生类中如果重写虚函数，那么派生类就会调用那个重写的虚函数。

对于虚析构函数，有的时候是必须写的，就是父类的指针指向子类（且子类必须是new去申请内存）的时候，如
`Product* p = new MilkTea();` 须知，MilkTea是继承的父类Product
这时候父类的析构函数就必须带virtual，因为如果没有带virtual，那么在析构的时候子类函数就不会被析构了，更简单的说：**父类指针指向子类对象**时，delete 只会调用父类析构，**子类析构不执行** → 内存泄漏。（子类不用重写析构函数，除非子类自己new申请了内存），这也是多态性的体现之一。
当通过基类指针去 `delete` 一个派生类对象时，基类的析构函数必须是 `virtual`，否则会导致未定义行为（通常派生类部分不会被析构，造成资源泄漏）。

如果父类指针想调用子类的函数，可以通过虚函数实现，比如
```Cpp
class Product {  
protected:  
    string id;  
    string name;  
    double price;  
    ProductType type;  
public:  
    Product(string i, string n, double p, ProductType t)  
            : id(i), name(n), price(p), type(t) {}  
    virtual ~Product() = default;  
  
    string getId() const { return id; }  
    string getName() const { return name; }  
    double getPrice() const { return price; }  
  
    virtual void showInfo() const {  
        cout << "ID: " << id << " | 名称: " << name  
             << " | 价格: ¥" << fixed << setprecision(2) << price << endl;  
    }  
};  
  
class MilkTea : public Product {  
private:  
    string size;  
    string sugarLevel;  
    string iceLevel;  
public:  
    MilkTea(string i, string n, double p, string s, string sugar, string ice)  
            : Product(i, n, p, TEA), size(s), sugarLevel(sugar), iceLevel(ice) {}  
  
    void showInfo() const override {  
        Product::showInfo();  
        cout << "  规格: " << size << " | 糖度: " << sugarLevel  
             << " | 冰度: " << iceLevel << endl;  
    }  
};
```
这个里面父类写了`virtual showInfo`,而子类把这个函数重写了，此时指针p在调用`showInfo`
的时候就会去调用子类重写的函数

# 9.内嵌对象

**内嵌对象**：一个类里，把**另一个类的对象**当作自己的**成员变量**，这个被包含的对象，就叫**内嵌对象**，也叫**组合对象**。
简单来说，就是在一个类里面写了另一个类的对象，如下
```Cpp
// 先定义一个类
class Heart {
public:
    void beat() {}
};

// 另一个类，包含上面类的对象
class Person {
    // 内嵌对象：把Heart的对象当成员
    Heart h;  
};
```
这里的`Heart h`就是内嵌对象
