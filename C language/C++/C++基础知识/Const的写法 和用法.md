`const` 在 C++ 中的位置不同，含义完全不同。可以归纳为 **3 种主要位置**：

---

## 1. 修饰变量（类的对象） —— 写在类型前后（效果一样）

cpp

复制

下载

const int a = 10;
int const a = 10;   // 完全等价

- 表示变量值**不可修改**
    

---

## 2. 修饰指针 —— 看 `const` 在 `*` 的哪一侧

|写法|含义|
|---|---|
|`const int *p`|指向常量的指针（**所指对象**不可改，指针可改）|
|`int const *p`|同上（等价）|
|`int * const p`|常量指针（**指针本身**不可改，所指对象可改）|
|`const int * const p`|两者都不可改|

记忆口诀：**`const` 在 `*` 左边修饰指向的内容，在 `*` 右边修饰指针本身**

---

## 3. 修饰成员函数 —— 写在参数列表后面

cpp

复制

下载

void func() const;   // 常成员函数

- 表示该函数**不会修改**对象的成员变量（`mutable` 除外）
    
- **只能写在函数声明/定义中**，不能写在调用处
    

---

## 4. 修饰函数返回值

cpp

复制

下载

const int& getValue();   // 返回常量引用
const int getValue();    // 极少用，返回常量值

- 防止返回值被修改（主要用于引用/指针返回值）

***
const 和 非const的使用关系，可以这么理解，我们把const想象为只读，把非const想象为只读+只写
const对象访问 非const对象是非法的，因为const只允许只读，但是非const却允许读和写
非const 访问 const是合法的，因为const是只读承诺，非const当然可以只读不写
