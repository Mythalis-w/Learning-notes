
对于栈：特点：自动分配、自动释放、速度快、空间小
写的局部变量都在栈上，如
```C++
int main(){ 
	 A a; // a 在栈上 
	int x; // x 在栈上 
}
```
2. **规则**：

- 进函数就自动开辟空间
- 函数结束**立刻自动销毁**( 离开当前作用域（`}`）就会销毁 )，自动调用析构(注意是main函数结束)
- **不用你手动管内存**
- 空间有限，不能开超大数组


而对于堆：手动分配、手动释放、速度慢、空间超大
我们new去申请内存都是在堆上去申请内存的
```Cpp
A* p = new A; // 对象在堆上，指针p本身在栈上 
A* p2 = new A[2]; // 数组对象全在堆上
```

2. **规则**：

- 必须用 `new` 手动申请
- 必须用 `delete / delete[]` **手动释放**
- 不写 delete → **不调用析构、内存泄漏**
- 空间很大，适合存大数据、对象数组
