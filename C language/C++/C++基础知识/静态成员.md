这一部分在类与对象里写过[[类与对象#7.静态成员]]
这里主要写下不是类的情况

首先，在类的情况下，静态成员变量必须类外初始化，但是在函数里不用，函数里直接初始化就行，且必须函数内初始化，不能函数外，即
`int add::sum = 0`
这个做法是错误的，因为add只是一个函数，不是类
```Cpp
#include <iostream>
using namespace std;

int add(int n){
    static int sum = 0;
    sum += n;
    return sum;
}

double add(double n){
    static double sum = 0.0;
    sum += n;
    return sum;
}
```
函数内的静态成员在每次初始化的时候仅会调用一次，此后不会在调用且在main未结束的时候会一直保存
C++会通过add重载来选择调用哪一个sum,并不会乱用，但是不好的地方是，函数内的静态成员无法像类(`Myclass::sum`)一样被外部访问，只能通过函数在不改变值的情况下去访问
```Cpp
int getIntSum(){
    return add(0);
}
double getDoubleSum(){
    return add(0.0);
}
```
