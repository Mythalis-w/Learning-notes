# 1 .iomanip
它是 C++ 的**输入输出流格式化头文件**,一些格式化的函数需要这个头文件

`fixed` 强制让小数用「固定小数点形式」显示
 setprecision(n) 确定小数点位数
```C++
cout << 12.0;   // 输出 12
cout << 16.5;   // 输出 16.5

cout << fixed << 12.0;   // 输出 12.000000（默认6位小数）
cout << fixed << setprecision(2) << 12; // 输出：12.00
```

# 2 .stdexcept
它是 C++ 标准头文件，里面定义了一堆**系统自带的标准异常类**：

- `std::exception`
- `std::runtime_error`
- `std::logic_error`
- `invalid_argument` 等等

专门用来**提供现成的异常基类**给开发者继承使用。
一般来说，只要类继承了系统的exception类型，就必须要有，不然就要自己手写异常类(自己用enum去定义一个异常类说明异常都有什么，然后写一个异常总类去管理异常)

```C++
// ===================== 自己的 enum 异常类型 =====================
enum ExceptionType {
    NULL_POINTER,
    INVALID_VALUE,
    NOT_FOUND,
    OUT_OF_STOCK,
    UNKNOWN_ERROR
};

// ===================== 纯手写异常类，不继承任何东西 =====================
class AppException {
private:
    ExceptionType type;
    string message;  // 只用 C++ string
public:
    AppException(ExceptionType t, const string& msg)
        : type(t), message(msg) {}

    // 获取类型
    ExceptionType getType() const {
        return type;
    }

    // 自己写一个获取信息的函数（不用 what！）
    string getMessage() const {
        return message;
    }
};

int main(){
    catch (const AppException& e) {
        switch (e.getType()) {
            case NULL_POINTER:   cout << "【空指针错误】"; break;
            case INVALID_VALUE:  cout << "【数据非法】"; break;
            case NOT_FOUND:      cout << "【找不到资源】"; break;
            case OUT_OF_STOCK:   cout << "【库存不足】"; break;
            default:             cout << "【未知错误】"; break;
        }
        // 用自己写的 getMessage()！不用 what()！
        cout << e.getMessage() << endl;
    }
}
```

这个就是自己手写一个异常的处理，不用std中提供的 stdexcept头文件
