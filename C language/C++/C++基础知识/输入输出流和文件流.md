 首先需要注意的是，在官方的话术中，我们所说的输入输出都是相对于程序来说的，程序的输出就是文件的输入（往里面写入）；程序的输出就是读取文件里面的数据来输出到一个位置（显示器）（文件读取）
# 1.流的介绍
流一般和物理设备关联
输入流一般是从键盘、鼠标流向内存；输出流则一般从内存流向物理设备
```Cpp
cout << "Hello";
int a;
cin >> a;
```
Hello会从内存中通过<<传给输出流cout，输出流会缓存在合适的时候传给设备
cin则是需要从键盘上提取一个值，通过>>传给输出流cin，再由cin给内存变量a

C++中包含4个预定义的流对象：
- 标准输入流（对象）cin
- 标准输出流（对象）cout  (ostream)
- 非缓冲型的标准出错流（对象）cerr
- 缓冲型的标准出错流（对象）clog
cerr clog都是输出流，用法同cout，但是cerr和clog不能进行重定向，只能输出到显示器；cerr没有缓冲，直接输出到显示器，主要用于调试程序用

## 格式操纵符
格式操纵符（Manipulator）是用于控制输入/输出格式的特殊符号，定义在 `<iomanip>` 头文件中（部分在 `<iostream>` 中）

| 类别    | 操纵符                           | 作用                     | 持久性         |
| ----- | ----------------------------- | ---------------------- | ----------- |
| 进制转换  | `dec` / `hex` / `oct`         | 设置十进制/十六进制/八进制         | 持久（影响后续所有）  |
| 宽度控制  | `setw(int n)`                 | 设置下一个输出的最小宽度           | 仅一次（仅影响下一个） |
| 填充字符  | `setfill(char c)`             | 设置宽度不足时的填充字符           | 持久（影响后续所有）  |
| 对齐方式  | `left` / `right` / `internal` | 左对齐/右对齐/符号左对齐数值右对齐     | 持久（影响后续所有）  |
| 浮点数格式 | `fixed` / `scientific`        | 定点表示法/科学计数法            | 持久（影响后续所有）  |
| 精度控制  | `setprecision(int n)`         | 设置精度(默认按有效数字显示)        | 持久（影响后续所有）  |
| 显示符号  | `showpos` / `noshowpos`       | 显示正号/不显示正号             | 持久（影响后续所有）  |
| 大小写   | `uppercase` / `nouppercase`   | 十六进制用大写/小写             | 持久（影响后续所有）  |
| 布尔格式  | `boolalpha` / `noboolalpha`   | true/false 输出 / 1 0 输出 | 持久（影响后续所有）  |
| 基数显示  | `showbase` / `noshowbase`     | 显示进制前缀(0x/0) / 不显示     | 持久（影响后续所有）  |
| 流控制   | `endl` / `flush` / `ends`     | 换行+刷新 / 刷新 / 输出空字符     | 即时执行（不改变状态） |

注意：`width()` 是 `ios_base` 类的成员函数，**作用与 `setw()` 完全一样，但是cout不是操纵符**
```cpp
// 使用成员函数 width()
cout.width(5);
cout << 25 << 30 << endl;   // 输出 "   2530"（width只对第一个25生效）

// 使用操纵符 setw()
cout << setw(5) << 25 << 30 << endl;   // 输出 "   2530"（效果完全相同）
```

# 3.文件流
**C++ 文件流类 一般包括三种`ifstream`、`ofstream`、`fstream`**，而这三个流类都被放进了\<fstream>这个头文件里

 
| 类名       | 作用    | 默认打开方式   | 用途      | 理解               |
| -------- | ----- | -------- | ------- | ---------------- |
| ifstream | 读文件   | ios::in  | 从文件读取数据 | 程序的输入就是读取文件内容给程序 |
| ofstream | 写文件   | ios::out | 向文件写入数据 | 程序的输出就是写入        |
| fstream  | 读 + 写 | 无（必须指定）  | 同时需要读写  |                  |
## 1.打开文件
```Cpp
#include <fstream>

std::ifstream fin("data.txt");      // 打开 data.txt 用于读取
std::ofstream fout("output.txt");   // 打开 output.txt 用于写入
std::fstream fio("both.txt", std::ios::in | std::ios::out); // 读写
```
其中fin是ifstream的一个对象，默认打开方式是ios::in，fout等同理

```Cpp
std::ifstream fin;
fin.open("data.txt");

std::ofstream fout;
fout.open("output.txt");
```
==其中open是ifstream里面的一个成员函数，而fin，fout等只是这个流类的对象，你改成my，随便的字符都可以，只要满足命名规范，大多时候都是因为要规范命名所以才这么写，没有写模式是因为有默认的打开方式==

### C++的文件流打开模式

| 模式                 | 含义                 | 备注             |
| ------------------ | ------------------ | -------------- |
| `std::ios::in`     | 读模式                | 不可用于`ofstream` |
| `std::ios::out`    | 写模式（默认会清空文件内容）     | 不可用于`ifstream` |
| `std::ios::app`    | 追加模式（写在文件末尾）       | 不可用于`ifstream` |
| `std::ios::binary` | 二进制模式（避免文本模式的换行处理） |                |
| `std::ios::trunc`  | 打开时清空文件内容          |                |
| `std::ios::ate`    | 打开后立即定位到末尾         |                |
## 2.检查文件是否打开
```Cpp
std::ifstream fin("data.txt");
if (!fin.is_open()) {
    std::cerr << "Failed to open file!" << std::endl;
    return 1;
}
```
或者简写
```Cpp
if (!fin) { /* 打开失败 */ }
```

其中`.is_open()` 是 **`std::ios` 类中的一个成员函数**，用于判断一个流对象是否成功关联并打开了一个文件。
由于继承关系，`std::ifstream`、`std::ofstream`、`std::fstream` 都继承了它，所以都可以用。

如果打开失败了，那个fin这个对象还是会创建,只不过是处于失败状态(0)，而上面if里面的都是去检测是否失败的.

## 3.写文件（`ofstream` / `fstream`）
```Cpp
#include <fstream>

int main() {
    std::ofstream fout("test.txt");

    if (!fout) {
        std::cerr << "Cannot open file for writing.\n";
        return 1;
    }

    fout << "Hello, file!" << std::endl;
    fout << 42 << " " << 3.14 << std::endl;

    fout.close();  // 可以省略（析构时自动关闭）
    return 0;
}
```

**注意**：
- `endl` 会换行并刷新缓冲区
- 默认打开方式 `ios::out` 会**清空原文件内容**，如果想追加，用 `ios::app`
```Cpp
std::ofstream fout("log.txt", std::ios::app); // 追加模式
```

## 4.读文件(`ifstream` / `fstream`）

注意：
- 用 `std::ifstream` 读取文件**不需要** `ios::out`，因为 `ifstream` 本身就是**输入流**，专门用来**从文件读取数据到程序**。
- `ios::out` 是用于**输出流**（如 `ofstream`）的，表示**从程序写入数据到文件**。
  平常我们认为out是出的意思，但是在这里输出流是写入到文件，对程序来说是输出，对文件来说是输入。

 方式1：用 `>>` 读取（按空格 / 换行分隔）
 ```Cpp
#include <fstream>
#include <iostream>

int main() {
    std::ifstream fin("test.txt");
    if (!fin) return 1;

    int a;
    double b;
    std::string s;

    fin >> s >> a >> b;   // 读取三个数据
    std::cout << s << ", " << a << ", " << b << std::endl;

    return 0;
}
 ```

## 文件流常用函数

### 1.写入(ofstream / ostream）

| 函数                            | 说明                  |
| ----------------------------- | ------------------- |
| `put(char c)`                 | 写入一个字符              |
| `write(const char* s, int n)` | 写入 n 个字节（二进制）       |
| `<<` 运算符                      | 格式化输出（int、string 等） |
### 2.读取(ifstream / istream）
| 函数                        | 说明                         |
| ------------------------- | -------------------------- |
| `get(char &c)`            | 读取一个字符                     |
| `get(char* s, int n)`     | 读取 n-1 个字符或遇到换行符，自动加 `\0`  |
| `getline(char* s, int n)` | 类似 `get` 但会读取并丢弃换行符        |
| `read(char* s, int n)`    | 读取 n 个字节（二进制）              |
| `peek()`                  | 查看下一个字符但不取出                |
| `gcount()`                | 返回最后一次 `get/read` 实际读取的字节数 |
| `>>` 运算符                  | 格式化输入（跳过空白）                |
### 3.指针定位（所有文件流）
|函数|所属流|说明|
|---|---|---|
|`seekg(offset, dir)`|`istream` / `ifstream`|移动读指针（g = get）|
|`seekp(offset, dir)`|`ostream` / `ofstream`|移动写指针（p = put）|
|`tellg()`|`istream` / `ifstream`|返回当前读指针位置|
|`tellp()`|`ostream` / `ofstream`|返回当前写指针位置|

**`dir` 取值：**
- `ios::beg` — 从文件头开始
- `ios::cur` — 从当前位置开始
- `ios::end` — 从文件尾开始
### 4.打开和关闭
| 函数                     | 说明         |                                      |
| ---------------------- | ---------- | ------------------------------------ |
| `open(filename, mode)` | 打开文件       | `ofstream`、`ifstream`、`fstream`新增的函数 |
| `close()`              | 关闭文件       |                                      |
| `is_open()`            | 检查文件是否成功打开 |                                      |
