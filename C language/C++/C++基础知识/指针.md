
主要讲下指针如何去判断类型
一般语法就是`子类类型* 变量 = dynamic_cast<子类类型*>(父类指针);`
如
```C++
Customer* customer;
// 尝试把 父类Customer指针 转成 子类会员指针 
MemberCustomer* mc = dynamic_cast<MemberCustomer*>(customer);
```
这时候，因为代码不知道customer是什么类型的指针，所以我们尝试转化，如果mc不是空指针，说明本来就是子类型，如果mc是空指针，说明是父类指针

这里这么理解，首先要明白，父类指针是可以指向子类指针的，customer作为一个指针，它可能指向的是子类指针，但是保存他的指针是父类，因此我们要做一个转换
