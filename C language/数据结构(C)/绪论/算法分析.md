# 1. 时间复杂度
也称渐近时间复杂度，$T(n) = O(f(n))$

## 1.计算频度

```C
for(int i=1; i<=n;i++)  // 执行 n+1 次 (n次循环，还有i=n+1的判断)
{
    for(int j=1;j<=n;j++)  // 执行 n*(n+1) 次 (n次循环，每一次循环都再n次循环，最后判断) 
    {
        c[i][j] = 0;  // 执行 n*n 次
        for(int k=1;k<=n;k++)  // 执行 n*n*(n+1) 次
        {
            c[i][j] = c[i][j] + a[i][k] * b[k][j]; //执行 n*n*n 次
        }
    }
}
```
执行n次，即频度为n
最后这一串代码的$f(n)=2n^3 +3n^2+ 2n+1$

## 2. 计算时间复杂度

若 $f(n)=a_mn^m + a_{m-1}n^{m-1} + ... + a_1n + a_0)$ 是一个m次多项式，则 $T(n)=O(n^m)$
在计算算法时间复杂度时，可以忽略所有低次幂和最高次幂的系数，这样可以简化算法分析，也体现出了增长率的含义。

所以上面的时间复杂度$T(n)=O(n^3)$
也可以直接看代码里运行最多的代码次数，嵌套三层循环，所以时间复杂度是$O(n^3)$

如果n在上面的代码为0，那只执行一次$T(n)=O(1)$

- 最好时间复杂度：算法在最好情况下的时间复杂度。
- 最坏时间复杂度：算法在最坏情况下的时间复杂度。
- 平均时间复杂度：算法在所有可能的情况下，按照输入实例以等概率出现时，算法计量的加权平均值。
对算法时间复杂度的度量，**通常只讨论算法在最坏情况下的时间复杂度**，即分析在最坏情况下，算法执行时间的上界。

### 常量阶
只要代码的运行次数里没有n，只有常数，那么算法复杂度就是$O(1)$
```C
for(int i=0;i<=1000;i++){
	for(int j=0;j<=10000;j++){
		s=0;
	}
}
```
上面这个代码的时间复杂度就是$O(1)$

### 线性阶
```C
for(int i=1;i<=n;i++){
    for(int j=1;j<=20;j++){
        for(int k=1;k<=30;k++){
            x++;
        }
    }
}
```
频度最高次是n的一次项，所有时间复杂度是$O(n)$

### 立方阶
```C
for(int i=1;i<=n;i++)        // 带n
    for(int j=1;j<=i;j++)    // 边界依赖i，依然和n相关
        for(int k=1;k<=j;k++)// 边界依赖j，依然和n相关
            x++;
```
第一个for是n，第二个for是$n(n+1)/2$ ，第三个for是 $n(n+1)(n+2)/6$ 
最高次是$n^3$，所以时间复杂度是$O(n^3)$

### 对数阶
```C
for(int i=1;i<=n;i=2*i){
	x++;
	s=0;
}
```
可以去列表格，==注意，表格里的第一次是进入循环后的第一次；for和while是不一样的，for在执行完循环的i才会更新，但是while在循环内就更新了==

| 次数  | 1     | 2     | 3     | 4     | ……  | t         |
| --- | ----- | ----- | ----- | ----- | --- | --------- |
| i   | 1     | 2     | 4     | 8     |     | ？         |
| i   | $2^0$ | $2^1$ | $2^2$ | $2^3$ |     | $2^{t-1}$ |
因为代码中`i<=n`
所以$2^{t-1}\le n$ ，最后解出来是$t\le log_2 n +1$   所以时间复杂度是$O(log_2 n)$ 

因此，在时间复杂度的计算中，不能只看for的个数，必要的时候还是要算的

### 例子
```C
int fun(int n=0){
	int i=0, sum=0;
	while(sum<n) sum += ++i;
	return i;
}
```

| 次数  | 1   | 2   | 3   | 4   | ……  | t          |
| --- | --- | --- | --- | --- | --- | ---------- |
| i   | 1   | 2   | 3   | 4   |     | t          |
| sum | 1   | 3   | 6   | 10  |     | $t(t+1)/2$ |
所以$t(t+1)/2 < n$  结果是$t \approx \sqrt{2n}$ ，最后$O(n^{1/2})$       
****
```C
x=0;
while(n>=(x+1)(x+1)){
	x=x+1
}
```

| 次数  | 1   | 2   | 3   | 4   | t   |
| --- | --- | --- | --- | --- | --- |
| x   | 1   | 2   | 3   | 4   | t   |
$n \ge (t+1)^2$  解出来结果是$t \le \sqrt{n} - 1$  ，所以为$O(n^{1/2})$ 
****
```C
int sum=0;
for(int i=1;i<n;i*=2){
	for(int j=0;j<i;j++){
		sum++;
	}
}
```

| 次数   | 1   | 2   | 3   | 4   | ……  | t         |
| ---- | --- | --- | --- | --- | --- | --------- |
| i    | 1   | 2   | 4   | 8   |     | $2^{t-1}$ |
| 内层次数 | 1   | 2   | 4   | 8   |     | $2^{t-1}$ |
又因为`i<n`，所以 $2^{t-1} < n$ ，所以$t < log_2 n +1$，时间复杂度不要求精确计算，所以$t = log_2 n +1$
而内层最高次数是一个等比数列求和
所以结果是$1*(1-2^t)/(1-2)$，代入 $t = log_2 n +1$ ，得到$n-1$
所以时间复杂度是$O(n)$
