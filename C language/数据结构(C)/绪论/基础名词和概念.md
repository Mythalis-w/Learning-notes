# 1. 数据、数据元素、数据项
- **数据(data)**：在计算机领域中指所有能被计算机识别、存储、处理、传输的符号的集合，是计算机程序加工处理的对象。
- **数据对象**：性质相同的数据元素的集合，是数据的一个子集。
- **数据元素(data element)**：数据中的一个“个体”，是数据的基本单位，又可称为元素、节点、顶点或记录。在计算机程序中通常作为一个整体进行考虑和处理。
- **数据项**：构成数据元素不可分割的具有独立含义的最小标识单位。

层级关系：**数据 > 数据对象 > 数据元素 > 数据项**
1. 数据项：不可再分的最小单元（学号、姓名）
2. 数据元素：一条完整记录（单行学生信息）
3. 数据对象：同类数据元素的集合（全部学生）
4. 数据：计算机可处理的所有符号集合

拿一个结构体举例
```C
typedef struct{
	int id;
	char name[20];
	int english;
	int math;
}Student;

int main(){
	struct Student arr[100];
	arr[0] = {1,"zhangsan",80,65};
}
```

其中`arr[0]`代表的是数据元素；`arr[0]`里面的`id、name……`指的是数据项；而`arr`全体代表着数据对象

| arr | id  | name     | english | math |
| --- | --- | -------- | ------- | ---- |
| 0   | 1   | zhangsan | 80      | 65   |
| ……  | ……  | ……       | ……      | ……   |
| 99  | 100 | lisi     | 90      | 90   |
每一行都是一个数据元素，除表头外每一个表格都是一个数据项，arr这一列是数据对象

# 2.数据结构
数据结构概念包括数据之间的逻辑结构，数据在计算机中的存储方式和数据的运算三个方面。
即数据结构包括：**逻辑结构；储存/物理结构；数据运算** 三个部分
