# 1.中缀表达式和后缀表达式
中缀表达式是我们人平常用的
后缀表达式是计算机去识别的

| 中缀表达式   | 后缀表达式   |
| ------- | ------- |
| $5+6*3$ | $563*+$ |
| $b*c/d$ | $bc*d/$ |

![[后缀表达式求值4.png]]

# 3.中缀表达式转换为后缀表达式
初始图如下![[中缀表达式转换为后缀表达式1.png]]
其中这个栈内压着一个0，这个0表示的是一个比较级，没有任何实际意义
比较级参考：![[比较级参考.png]]

中缀转换为后缀表达式有几个规则：
- 1.如果扫描到了操作数，直接输出
- 2.如果是运算符，则判断优先级，如果优先级大于栈顶元素，压入栈中；否则将栈顶元素出栈输出，然后将当前运算符压入栈中
- 3.当左括号在栈外时，属于最高优先级，当左括号在栈里时，属于最低优先级
- 4.如果是右括号，且栈顶元素不是左括号，持续出栈并输出，直到栈顶为左括号出栈结束最后将左括号也出栈（注意，左右括号不在输出内容内）
- 5.最后留在栈内的元素（除了0），全部出栈输出

第一步：是x，直接输出
第二步：是$/$，优先级是13，大于0，压入栈中     
第三步：是(，栈外优先级是17，压入栈内，优先级变成0
第四步：是i，直接输出
第五步：是$-$，优先级是12，大于0，压入栈内
第六步：是j，直接输出

第八步：是$*$，优先级是13，并非==大于==栈顶元素，根据规则2，除号输出，乘号压入栈内![[中缀表达式转换为后缀表达式4.png]]
第九步：y，直接输出。
